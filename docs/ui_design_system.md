# UI Design System

## Product Feel

R76 CertiScale should look like a serious laboratory and government-compliance dashboard. It should feel trustworthy, organized, and fast to scan.

## Color Palette

- Primary navy: `#1E3A8A`
- Secondary blue: `#1E40AF`
- Accent amber: `#B45309`
- Background: `#F8FAFC`
- Text: `#0F172A`
- Muted surface: `#E9EEF5`
- Border: `#CBD5E1`
- Pass green: `#166534`
- Fail red: `#DC2626`

## Why These Colors

Navy communicates authority, trust, and government-compliance seriousness. Amber is used only for important actions like report generation. Green and red are reserved for pass/fail states so compliance results are immediately clear.

## Typography

- Headings: EB Garamond
- Body/UI: Lato

This pairing gives the interface a formal report-like identity while keeping tables and forms readable.

## Layout Rules

- Left sidebar for module navigation.
- Dense dashboard metrics for rapid scanning.
- Forms use visible labels, not placeholder-only fields.
- Tables use clear column headers and status pills.
- Report preview should look like a formal document, not a marketing page.

## Accessibility

- Minimum 44px touch targets.
- Visible keyboard focus.
- Strong color contrast.
- Reduced motion support.
- Search input has accessible label.
